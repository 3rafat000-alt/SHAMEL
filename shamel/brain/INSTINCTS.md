# INSTINCTS — طبقة الثقة والترقية (Confidence & Promotion Layer)
**الغريزة = أصغر وحدة تعلّم فوق CORTEX — تحفيز واحد ← إجراء واحد**

```
HIPPOCAMPUS/CORTEX (بيانات مُلتقطة أصلاً عبر hooks → brain.db)
     ↓ (تحليل وتقييم — لا التقاط جديد)
INSTINCTS = تسجيل الثقة + قرار الترقية
     ↓ (project-scoped يُرقّى إذا استوفى الشرط)
scope: global (يُقرأ من كل مشاريع SHAMEL المستقبلية)
```

**مبدأ أساسي:** الغرائز تُشتق من بيانات HIPPOCAMPUS/CORTEX الموجودة أصلاً (يغذّيها hooks إلى `brain/db/brain.db`) — هذه طبقة **تحليل وتنقيح** فوق التقاط قائم، وليست خط جمع بيانات موازياً. لا حاجة لـ hooks إضافية؛ knw-lead وقادة الغرف يُطبّقون هذا المنطق يدوياً عند مراجعة إدخالات CORTEX.

---

## | ما هي الغريزة (What Is an Instinct)

وحدة ذرّية: **تحفيز واحد ← إجراء واحد**. تُخزَّن كـ frontmatter + جسم قصير:

```yaml
id: <slug>
trigger: <الشرط الذي يُفعّل هذه الغريزة>
confidence: 0.3–0.9
domain: <e.g. security | workflow | php | dart | general>
source: <الجلسة/الغرفة التي ولّدتها>
scope: project | global
project_id: <e.g. PRJ-SAKK — يُحذف إذا scope: global>
```

```markdown
## Action
[ما يجب فعله عند تحقق الشرط]

## Evidence
[الملاحظات التي تدعم هذه الغريزة]
```

## | صيغة تسجيل الثقة (Confidence Scoring)

| الحدث | التأثير |
|-------|---------|
| قيمة ابتدائية — 1-2 ملاحظة | 0.3 |
| قيمة ابتدائية — 3-5 ملاحظات | 0.5 |
| قيمة ابتدائية — 6-10 ملاحظات | 0.7 |
| قيمة ابتدائية — 11+ ملاحظة | 0.85 |
| تأكيد (نفس النمط يتكرر) | +0.05 |
| تناقض (ملاحظة لاحقة تعارض الغريزة) | −0.1 |
| اضمحلال (كل أسبوع بدون تعزيز) | −0.02 |

---

## | قاعدة الترقية (Promotion Rule)

`scope: project` → `scope: global` تلقائياً عند استيفاء **كل** الشروط معاً:

1. نفس `trigger`/`id` ظهر بشكل مستقل في **مشروعين مختلفين على الأقل** من مشاريع SHAMEL
2. متوسط الثقة عبر المشروعين **≥ 0.8**
3. `domain` ضمن القائمة الآمنة عالمياً: `security` · `workflow` · `general-best-practice`

**استثناء صريح:** غرائز نطاقات منطق الأعمال الخاصة بمشروع — مثل خاصية CCPayment في PRJ-SAKK — تبقى `scope: project` إلى الأبد، مهما تكرر ظهورها. لا تُرقّى أبداً لأنها ليست حقيقة عالمية عبر مشاريع SHAMEL المستقبلية.

## | من يُطبّق هذا (Who Applies This)

- **knw-lead / قادة الغرف:** يراجعون إدخالات CORTEX دورياً، يستخرجون المرشحين، يحسبون الثقة، يقرّرون الترقية
- **knw-memory-curator:** يوثّق الغرائز الجديدة هنا بصيغة frontmatter الموحّدة أعلاه
- **لا hooks جديدة:** منطق تحليلي يُطبَّق يدوياً فوق بيانات مُلتقطة أصلاً

---

## | مكان التخزين (Storage)

- `## project-scoped` — مصنّفة حسب `project_id`، لكل مشروع قسمه
- `## global-scoped` — الغرائز المُرقّاة فقط، بعد استيفاء شرط الترقية أعلاه
- المصدر الخام يبقى في `brain/db/brain.db` (FTS5) و `brain/CORTEX.md` — هذا الملف تقييم فوقها، لا بديل عنها
