# Architectural Decision Records

## ADR-001 — Fate of the Six Generations: Rescue → Tombstone → SHAMEL
- **Status:** Accepted
- **Context:** 6 coexisting generations, 8 entry points, golden assets untracked (GAP-01/03), dead layers polluting every grep (GAP-14).
- **Decision:** The binding order — *rescue waits for no one*. (a) Immediate rescue before any cleanup (114 scripts + browser-eyes + checklists from G1; orchestrator fork from MAIN; stash preserved). (b) Each generation's fate: G1 OpenCode → `archive/g1-opencode/` after rescue; G2 engine/ v5 → `archive/g2-engine-v5/` after capturing Article 11 + scanners; G3 v6 → ported nearly whole (core/ backbone); G4 org-rooms → governance merged into agent frontmatter via mapping table; G5 substrate → ported as `shamel_tools/core/`; G6 orchestrator → unified fork → `shamel_tools/pipeline/`. (c) Every burial = MANIFEST + git tag — tombstone, not zombie.
- **Consequences:** No unique code outside git; clean grep; one-time cost: fork merge and ID↔persona map.

## ADR-002 — Single Deterministic Dispatcher: `shamel` (Python) Replaces 8 Entry Points
- **Status:** Accepted
- **Context:** 5 executables named `sofi` ("PATH order silently decides"), 6 parallel task managers, byte-identical duplication between generations (GAP-06/15).
- **Decision:** One entry point `engine/bin/shamel` (pure Python — bash→python wrapper dies); one library `shamel_tools/` in 4 domains (core/nexus/brain/net) + `pipeline/`; `taskq.py` as the single state machine; `registry.py` (substrate) renamed `schemas.py`; pipeline reads `core/nexus/*.yaml` exclusively. `shamel doctor` fails on any concern with two implementations.
- **Consequences:** One fix reaches all; one name per concept; one-time cost: import rewrites + legacy db migration.

## ADR-003 — Single Agent Inventory: Source File + Generated Spawnable (No Manual Edit)
- **Status:** Accepted
- **Context:** 5 parallel inventories, 2 live definitions of the same 105 IDs with different behavior per branch (GAP-07), one generation with zero least-privilege (GAP-10).
- **Decision:** Single source `core/rooms/<NN>/agents/<id>.md` (automated frontmatter + G4 governance + persona + RCCF); `.claude/agents/` is a **deterministic derivative** via `shamel agents build`; `agentlint` fail-closed rejects: a file without explicit `tools:`, a literal model ID, a spawnable not matching its `pins.json` SHA-256.
- **Consequences:** `@agent` one = one behavior everywhere; rich persona without context cost (not injected into spawnable); cost: mandatory build step after any agent edit (enforced by hook + CI).

## ADR-004 — SHAMEL Independent Repo on Desktop; 15 Rooms; Worktrees Outside `.claude/`; Project Brain Inside Project Repo
- **Status:** Accepted
- **Context:** 3 diverging git lineages and scattered root tree (GAP-02); palette bleed from nesting worktrees under `.claude/` (GAP-05); live project + brain outside any VCS (GAP-01/09); 10-vs-15 room ambiguity (GAP-16).
- **Decision:** `~/Desktop/SHAMEL/` fresh independent repo — **lineage break**: built by rescue extraction from generations (ADR-001) not by inheriting Lorka's fragmented history (Lorka stays reference archive); official room map = **15** (the most complete coverage); worktrees in `.worktrees/` at repo root; each project its own repo with day-zero law and `_context/` committed with code; `paths.py` loud-fail.
- **Consequences:** One session = one constitution = one palette (end of "schizophrenia by startup directory" — GAP-08); sync→checkpoint→handoff loop actually executable; cost: PRJ-SAKK migration to its own repo (already the first urgent item).

## ADR-005 — Enforcement Doctrine: No Claim Without Fail-Closed Mechanism, Guards Self-Report
- **Status:** Accepted
- **Context:** Gate 6 declared above nonexistent deployment (GAP-04); "scheduled reflection" with no scheduler and oracle returning exit 0 on failure (GAP-11); brain contradicting code (GAP-12); hooks fail-open silently (GAP-20).
- **Decision:** Every system claim carries a named enforcement clause: gate advance = `validate_evidence()` fail-closed + adversarial gatekeeper + executable artifacts; reflection = real cron with `claude -p`; oracle = fallback API + `exit≠0` on failure; brain numbers = generated by `shamel brain counts` (code is truth); hooks remain fail-open (don't crash the session) but with failure counter visible in doctor — *monitor without blocking*; doctor+selftest+agentlint as CI gate on every repo.
- **Consequences:** "Paper automation" structurally impossible; trust in gates returns because they measure executable reality; cost: rigor slows optimistic announcements — and this is intentional.

## ADR-006 — Document Path Conflict Resolution
- **Status:** Accepted
- **Context:** 6 design documents with conflicting path conventions (ARCHITECTURE, PRD, BRAIN, PROTOCOL, AUTOMATION, PROJECT-STRUCTURE).
- **Decision:** Resolved differences by unanimous vote:
  (a) Dispatcher location: `engine/bin/shamel` (ARCHITECTURE §3.3) — not `os/bin/`.
  (b) Runtime home: `brain/db/` gitignored (ARCHITECTURE §2) unifies `.claude/memory/` and `.shamel/`; logs in `brain/db/logs/`.
  (c) Substrate schema module: `schemas.py` — not `schemadb.py`.
  (d) Single scheduling file: `cron/shamel.crontab` driven by `shamel automation install/status`.
  (e) Official hook count: 7 (5 migrated + PreCompact + SubagentStop).
- **Consequences:** All 6 design documents corrected to match in single commit. Future: any new document path conflict resolved via new ADR — never silently.
